Fentastic Oneadvent Skin

Custom Kodi skin build based on FENtastic by Ivar Brandt.

Install in Kodi

  1. Add this source in Kodi File Manager: https://1advent.github.io/kodiskin/
  2. Open Install from zip file
  3. Select repository.oneadvent-1.2.7.zip
  4. Open Oneadvent Repository, then Look and feel, then Skin
  5. Install Fentastic Oneadvent Skin

The helper add-on required by the skin is bundled in this repository.

Files

  • repository.oneadvent-1.2.7.zip
  • script.fentastic.helper-1.0.11.zip
  • skin.fentastic.oneadvent-1.2.7.zip
