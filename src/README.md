# Fentastic Oneadvent Skin

A customized Kodi Omega skin based on FENtastic, tailored for a simplified Oneadvent layout and FenLight usage.

## Highlights
- Unique Kodi add-on ID: `skin.fentastic.oneadvent`
- Simplified home menu
- FenLight/FenLightAM search integration
- Custom poster widgets
- Green default home background
- Oneadvent branding

## Build version
Current public version: `1.0.1`

## Packaging
Use the repository build script from the project root:

- `tools/build_repo.py`

That script rebuilds:
- the skin zip
- the Kodi repository zip
- `addons.xml`
- `addons.xml.md5`

## Publish to GitHub
1. Create a GitHub repo named `oneadventskin`
2. Replace `YOUR_GITHUB_USERNAME` in `tools/build_repo.py`
3. Run the build script
4. Push the full `oneadventskin` folder contents to GitHub
5. Share the repository zip or install source with users
